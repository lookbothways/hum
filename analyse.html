Record with your phone's own voice recorder — a native app holds the microphone when the screen is off and other apps are in front, which no web page can do. Uncompressed WAV is best; if your recorder only makes m4a, this page will still decode it, but the whole file has to fit in memory, so do long ones on a computer. Set the start time from the recording's own timestamp so the log lines up with the clock.
